# Project HIROPON 第4章

## タイトル

「初めての国会で、大失敗しました。」～消えた民意を取り戻せ～

## 起動

`index.html` をブラウザで開きます。外部通信・外部ライブラリは不要です。

## 1周の構成

- 基礎：5分野×2問＝10問
- 数字コード：6問
- 手続き並べ替え：3題
- ボス：4問
- 合計：23問、想定25～30分

## 保存

会話位置、挑戦中のステージと問題位置、正答数、誤答分野、クリア状態を `localStorage` に保存します。

## 表示

- PC・iPad横向きでは16:9のゲーム枠を中央表示
- 幅800px以下では縦積みレイアウトへ切替
- タッチ選択肢は高さ58px以上
- 第4章専用の政治の都背景、勉三・ヒロポン・民意の精霊、15マス盤面を収録
- タイトル・正誤・かけら獲得・解放・ボス・章クリアの短い効果音をブラウザ内生成
- 音声ON／OFF対応（音声なしでも進行可能）

## 画像構成

- 政治の都：タイトル・導入
- 15マス盤面：5分野の基礎問題
- 数字コードの間：人数・年数・日数・割合
- 手続き回廊：法律・解散・憲法改正の並べ替え
- 民意なき政治：総合ボス戦
- 民意ルート復旧：章クリア
- 勉三・ヒロポン・民意の精霊：会話・コマ用個別素材

## 配布

静的ファイルのため、GitHub PagesまたはGASへ移植できます。公開は最終承認後に行います。
